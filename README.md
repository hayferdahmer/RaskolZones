**RaskolZonez** — слой земель сервера «РАСКОЛ | ДВЕ КОРОНЫ»: зоны, их границы, владения и правила, которые держат два королевства на своих местах и не дают им передраться из-за каждого холма.

## 🗺️ Карта земель

```text
╔══════════════════════════════╦══════════════════════════════╗
║   РАССВЕТ · земли света      ║   ВАЛЬРАДИС · земли пепла    ║
╠══════════════════════════════╬══════════════════════════════╣
║  /\    /\/\       .  *  .    ║  .  *  .       /\/\    /\    ║
║ /  \  /    \    Дубрава      ║   Пепельник   /    \  /  \   ║
║      ,,,  ,,,     ,,,        ║      ^^^   ^^^     ^^^       ║
║   +-----------+  ~~~~        ║     +-----+     Багровый     ║
║   | СТОРОЖКА  | ~ Брод ~     ║     | ## ##|      перевал    ║
║   |  (*) очаг |  ~~~~        ║     | БАШНЯ|    ======>      ║
║   +-----------+              ║     +-----+                  ║
║  o--o--o--o--o--o--o--o--o   ║  o--o--o--o--o--o--o--o--o   ║
╚══════════════════════════════╩══════════════════════════════╝
```

<sub>Пунктир `o--o--o` — межа. Посреди карты проходит трещина раскола: то, что слева, принадлежит Рассвету, то, что справа, — Вальрадису.</sub>

## 📜 Свитки

<details open>
<summary><b>Свиток I · Две короны, две земли</b></summary>
<br>

| Корона | Цвет | Что стережёт |
| ------ | ---- | ------------ |
| **Рассвет** | золото | порядок, клятву, тёплые окна сторожек |
| **Вальрадис** | багрянец | пепел, долг, огни на башнях |

Зона принадлежит одной из корон или не принадлежит никому. От этого зависят правила входа, строительства и боя на её земле.

<!-- ✎ Уточни: как именно корона влияет на зону. -->

</details>

<details>
<summary><b>Свиток II · Виды земель</b> <i>(пример — замени на свои)</i></summary>
<br>

| Земля | Нрав | Правила |
| ----- | ---- | ------- |
| 🏡 Приют | тихая, уютная | без PvP, без разрушения блоков |
| 🛒 Торжище | шумная | торговля разрешена, бой запрещён |
| ⚔️ Пограничье | тревожная | PvP включён, ресурсы богаче |
| 🏰 Королевская | строгая | вход и строительство только по праву |

</details>

<details>
<summary><b>Свиток III · Таверна команд</b> <i>(пример — замени на свои)</i></summary>
<br>

| Команда | Право | Назначение |
| ------- | ----- | ---------- |
| `/zonez` | — | Где я стою и чья это земля |
| `/zonez list` | — | Все земли королевства |
| `/zonez create <имя>` | admin | Заложить новую зону |
| `/zonez reload` | admin | Перечитать конфиги |

</details>

<details>
<summary><b>Свиток IV · Установка</b></summary>
<br>

```bash
mvn -B clean package
cp target/raskol-zonez-*.jar plugins/
# перезапуск сервера
```
